# Changelog

## Unreleased (0.1.0 working baseline)

- Initial opt-in XeLaTeX package and scoped font controls.
- Explicit named symbol declarations and mathematical atom classification.
- Chinese Unicode character insertion and Arabic-script insertion.
- Arabic-Indic numeral conversion for ASCII digits and decimal points.
- Minimal standalone examples, regression smoke tests, unicode-math interoperability,
  PDF Unicode extraction checks, and CI.

This is a development baseline, not a historically verified notation catalogue
or a stable public release.
